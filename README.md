# Repository Overview

This repository contains a collection of various software projects and assignments, likely from different courses or areas of study. Each major project is organized into its own top-level directory.

## Project Directories

Below is a list of the main project directories within this repository:

*   **`Internet_Computing/`**: Contains examples, assignments, and materials related to internet computing concepts. For specific SVN usage guidelines relevant to this project, please refer to `Internet_Computing/IC_Repo/ic_svn_work/readme.txt`.

*   **`Patient_Medication_Management_System/`**: This directory houses a web application designed for managing patient medication.
    *   **Setup and Usage**:
        1.  Navigate to the `Patient_Medication_Management_System/` directory (the subfolder also named `pmms` mentioned in its readme seems to be the project root itself).
        2.  Install dependencies: `npm install` and `npm install express`.
        3.  Ensure MongoDB is downloaded and running.
        4.  Start the NodeJS server: `node ./bin/www`.
        5.  Open a web browser and go to `http://localhost:3000` to view the application.
    *   For more details, see the `Patient_Medication_Management_System/readme` file.

*   **`Programming_Languages/`**: This directory includes assignments, code examples, and other materials related to the study of programming languages. Several subdirectories exist, some of which contain their own `readme.txt` files with SVN guidelines (e.g., `PL_Repo/readme.txt`, `chen_koluguri/readme.txt`, `koluguri_sleem_ticer/readme.txt`).

*   **`SDP/`**: This directory likely contains materials for a "Software Design Project" (SDP). It includes a `prolancers` subdirectory with code and documentation.

*   **`Software_Design_projects/`**: Contains various assignments and projects related to software design principles and practices. For specific SVN usage guidelines, refer to `Software_Design_projects/readme.txt`.

## Version Control (SVN)

Many of the projects in this repository were managed using Subversion (SVN). You may notice `.svn` directories within the project folders; these are metadata directories used by SVN and can generally be ignored if you are not using SVN.

If you are working with SVN, please adhere to the following general guidelines, which were found in several project-specific `readme.txt` files:

*   Check in your work frequently.
*   Do not check in binary files or files generated by compilers or other tools (e.g., build artifacts).
*   Avoid deleting files directly. If a file is no longer needed, consider its history before removal. If you need to move a file, use the `svn mv` command instead of deleting and recreating it, as this preserves the change history.
*   Do not use spaces in file or directory names. For example, use `MyProjectFile` instead of `My Project File`.
*   If you are unsure about any SVN operations, please consult with the project maintainer or a team member familiar with SVN.
